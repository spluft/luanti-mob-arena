# mob_arena — PvP-арена из мобов с наградами

Собственный world-мод (2026-09-05), запрос: «pvp мобы, выбрать тип и
количество, за победу награда».

## Команды
- `/arena <тип> [кол-во]` — заспавнить волну рядом с собой.
  Типы: `easy` (зомби+серебрянка), `normal` (+скелет, паук),
  `hard` (+pillager, husk, creeper), одиночные: zombie, skeleton, spider,
  creeper, pillager, witch, husk, stray, drowned, silverfish, enderman,
  slime. Кол-во 1..`mob_arena.max_count` (12).
- `/arena_stop` — убрать своих волновых мобов.
- Волновая моба: nametag `⚔ <ник>`, статична к рандом-деспавну
  (`persist_in_peaceful` staticdata как у `/spawn_mob`).

## Награда
- За убийство волновой мобы: `mob_arena.reward_emeralds` (1) изумруд
  (`mcl_core:emerald`) + орб опыта 5–12 (`mcl_experience.throw_xp`).
  Считается по факту killing blow — награда тому, кто ударил (может быть
  и второй игрок/питомец).
- Зачистка всей волны: бонус `mob_arena.wave_bonus` (2) изумруда владельцу.

## Как у technically под капотом
- Убийства ловятся обёрткой над `mcl_mobs.mob_class.on_punch`
  (combat.lua:516 — центральный путь урона мобов; health уменьшается
  внутри, обёртка видит `dead`/`health<=0` после вызова оригинала).
  Патч таблицы class, а не defs → покрывает всех мобов.
- Волновые мобы помечены `ent._arena_owner`; спавн через
  `core.add_entity(name, core.serialize{persist_in_peaceful=true})`.
- `depends = mcl_mobs`; настройки `mob_arena.*` (settingtypes.txt).

## Настройки (world minetest.conf)

## v2 (05.09, вторая волна фич) — арена из блоков + авто-волны

### Разметка арены блоками (фича по запросу Коли)
- **Золотой блок (sneak+place) = угол A, алмазный блок = угол B.** Только для
  игроков с привилегией `server`. Регион = box между углами (пол = y меньшего
  угла, вверх 16). Валидация стороны 6..48 (setting `mob_arena.max_side`).
- Маркеры после разметки можно хоть сломать (регион в mod_storage);
  **копание маркера = снятие региона** (защита от «забыли где арена»).
- `/arena_show` — подсветка периметра частицами (node-tile золото, 1 сек).
- `/arena_info` — размер/волна, `/arena_off` — снять регион (admin).

### Ограничение мобов регионом
- Спавн волны: только случайные точки внутри региона с твёрдым полом и
  ≥4 м от игроков (40 попыток).
- **Containment**: globalstep раз в 1 сек — волновой моб за границей (+0.5
  margin) удаляется, слот волны расходуется БЕЗ награды (безescaping-фарма).
- При старте волны зачищаются **дикие** мобы внутри региона (изоляция,
  важно при x2 кап mcl_mob_density).

### Авто-волны
- После зачистки: «передышка» `mob_arena.wave_pause` (12 с) → следующая
  волна +1 моб к базе, без лимита серий, пока `/arena_stop` или регион цел.
- sid_seq защищает от «призрачных» after()-таймеров после stop/новой волны.

### Настройки v2
`mob_arena.wave_pause` (12), `mob_arena.max_side` (48).

## v3 (05.09) — быстрый круговой режим (без блоков)

По запросу: можно не размечать блоками — `/arena` без box-региона создаёт
**круг радиуса `mob_arena.radius` (дефолт 12, макс 30) вокруг игрока**.

Ключевые решения:
- **Центр фиксируется в момент `/arena`** (не следует за игроком) — иначе
  containment превращается в «моб убегает, арена телепортируется», абсурд.
- Region абстракция: `box` (маркерный, persistent) | `circle` (быстрый, per-wave).
  Containment/спавн/очистка диких работают по обеим одинаково.
- Спавн в круге: равномерный по площади (`sqrt(random)*r`), минимум 3 м от
  центра, пол обязателен, ≥4 м от игроков.
- Маркерный box по-прежнему приоритетен: задан — волны в нём; не задан — круг.
- `/arena_show` без box показывает круг по месту стояния.
- Волна хранит свою `reg` — рестарт/смена mode посреди серии не ломает серию.

Настройки v3: `mob_arena.radius` (12, 6..30).

Верификация: luaparser PARSE OK; stdout 13:55 UTC `[MOD] mob_arena v3
loaded: ... radius=12, box=not set`, 0 ERROR.

## v3.3 (05.09) — ГЛАВНЫЙ ФИКС: param:split("%s") не работает в Luanti

Симптом всех трёх тестов: "/arena invoked" в логе есть, spawn-трейла нет,
ошибок нет. Мобы НЕ спавнились вообще никогда (ни в v3.1, ни в v3.2 —
прошлый "ipairs-фикс" был ложным следом, band-баг существовал но волна
до него не доходил).

Корень: Luanti переопределяет string:split(str, sep, plain) — plain=true
по умолчанию, т.е. ":split("%s")" ищет ЛИТЕРАЛЬНЫЙ "%s" как разделитель.
"easy 3" → parts={"easy 3"} → TYPES["easy 3"]=nil → return false,"Тип: ..."
— refusal шёл в вывод slash-команды, Коля его не видел (не разглядывал
строку после /arena).

Фикс: `local it = param:gmatch("%S+")` (чистый Lua паттерн-итератор).
Плюс core.log на bad-type ветку.

Урок: в Luanti НИКОГДА не использовать str:split с Lua-паттернами —
только gmatch, либо split(s, " ", true) с явным литералом.

## v6 (05.09) — экономика «копилки»: выплата только после всех волн, смерть = 0

Требование Коли: изумруды выдаются только после прохождения ВСЕХ волн; смерть
во время арены обнуляет копилку; каждая зачищенная волна = +1 в копилку.
Пример из ТЗ: 4 волны, смерть на 3-й (зачищенной) → выплата 1, а не 2 — т.е.
волна, на которой умер, не засчитывается даже если мобов добить.

Реализация:
- purse[owner] — банковский счёт сессии (копилка), живёт пока активна арена.
- Волна зачищена БЕЗ смерти → +REWARD_EMERALDS (дефолт 1) в копилку.
- Смерть (register_on_dieplayer) → копилка=0 И волна, на которой умер,
  помечается no_reward (даже если её потом зачистят — не платит). Волны
  ПРОДОЛЖАЮТСЯ: пережил — заработай заново.
- После финальной волны (total, по умолчанию mob_arena.waves_total=3,
  третьим аргументом: /arena easy 3 5 — 5 волн) → выдача копилки целиком
  (bank=0 → сообщение «копилка пуста», ничего не выдаётся).
- /arena_stop и выход из игры → forfeit (сообщение «копилка сгорела: N»).
- /arena_info показывает копилку и прогресс волна N/total.
- За килл по-прежнему только XP-орб.

Волны теперь считаются до total, а не вечно: авто-волны останавливаются на
последней (выдача) или при /arena_stop. Дефолтный прогон: 3 волны
(3/5/8 мобов при base=3).
